The six themes

01

Silent scoring corruption

Exceptions are stored as the literal answer text “Error: …”, unparseable judge output is stored as {} and counted a success, and missing answers become “N/A” — all fed to evaluators and graded 1–3. Zero-filled per-mode means then fabricate name/position bias the size of a whole score.

02

Incomplete model-rename churn

New names in models.py never reached PROVIDER_MAP, shortcuts, three figure color maps, the judge default, the UI, or the docs. One path crashes outright (figure generation, KeyError); the rest degrade in silence.

03

Broken crash-recovery

get_last_completed_phase checks only that files exist — it ignores Phase 3’s complete flag and never sees phases 4–5. So --resume skips a half-finished Phase 3 and re-runs the paid Phase-5 judge on stale data.

04

Dead concurrency control

The provider semaphore is taken once per five-request batch instead of per request, so PROVIDER_CONCURRENCY never actually throttles — the knob added to prevent 429 / MAX_TOKENS storms does nothing.

05

Validation-script drift

Three near-identical validators (GSM8K / TruthfulQA / MMLU) have drifted: robust answer extraction, the total>0 filter, checkpointing, tie-averaged ranks, and CIs each landed in one script and were never ported to the others.

06

Provider & packaging gaps

Null-content refusals crash instead of registering as refusals; three providers ignore the timeout; and scipy is missing from core deps, so every documented command crashes at import right after pip install -e .

Method. 11 subsystem reviewers ran in parallel, findings were deduplicated, then each was re-checked by an adversarial verifier told to refute it (defaulting to refuted when uncertain); a completeness critic then opened a second gap round, itself verified. Seven findings were severity-adjusted by the verifier (noted inline). Caveat: a few findings anchor to an uncommitted working-tree state (e.g. the gemini-3.7-flash rename) — re-verify against current HEAD before fixing.
